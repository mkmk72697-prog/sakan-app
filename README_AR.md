# سكن — مشروع أندرويد

هذا مشروع Android Studio يغلّف نسخة الويب الحالية من «سكن» داخل تطبيق Android باستخدام WebView.

## ما يعمل في هذه النسخة
- واجهة عربية افتراضيًا مع خيار الإنجليزية.
- يعمل دون إنترنت لأن صفحة التطبيق مضمّنة داخل التطبيق.
- حفظ البيانات محليًا على نفس الجهاز باستخدام LocalStorage.
- اختيار ملف JSON لاستعادة نسخة احتياطية.
- حفظ النسخة الاحتياطية إلى ملف عبر نافذة حفظ ملفات أندرويد.

## بناء APK
1. فك ضغط المشروع.
2. افتح مجلد `sakan_android` في Android Studio.
3. انتظر مزامنة Gradle ثم اختر **Build > Build APK(s)**.
4. ستجد ملف APK التجريبي في `app/build/outputs/apk/debug/app-debug.apk`.

يمكن كذلك رفع المشروع إلى مستودع GitHub وتشغيل workflow باسم **Build Sakan APK** من تبويب Actions، ثم تنزيل artifact باسم `sakan-debug-apk`.

## تنبيه مهم
هذه النسخة تحفظ البيانات على الجهاز فقط. مزامنة البيانات بين عدة أجهزة عبر الإنترنت ليست مفعّلة؛ تحتاج إعداد قاعدة بيانات وخدمة خلفية. وملف APK الناتج من إعداد debug للاختبار والتثبيت الشخصي، وليس إصدار متجر موقّعًا للنشر.
